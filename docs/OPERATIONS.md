# Operations

Commands, data pipeline, and maintenance procedures.

## npm scripts

| Command | Script | Purpose |
|---------|--------|---------|
| `npm run dev` | `next dev` | Local dev server :3000 |

| `npm run apply:animal-parents` | Supabase script | Apply parent columns |

## Local development (JSON mode)

```bash
npm install
npm run db:reset    # Rebuild data/farm.db.json from source CSVs
npm run dev         # http://localhost:3000 — no login required
```

Requirements for import:

1. Source CSVs in `Data/Notion/` and `Data/Google sheets/`
2. Audit resolutions in `data/audit-resolutions.json` (generated by audit step)

### Expected outcome after db:reset

```
Settlement: Monis +192,247 / Saad −192,247
meta.settlementVerified: true
```

If verify fails, do not commit changed `farm.db.json` without fixing import logic.

## Import pipeline

```
Data/Notion/*.csv  ──┐
Data/Google sheets/*.csv ──┼──► audit-data.mjs ──► data/audit-resolutions.json
                             │                              │
                             └──► import-all.mjs ◄────────────┘
                                        │
                                        ▼
                              data/farm.db.json
                                        │
                                        ▼
                                   npm run verify
```

### Source files

| Source | Content |
|--------|---------|
| `Data/Google sheets/Farm Expense - Awais.csv` | Awais Palai customer ledger |
| `Data/Google sheets/Farm Expense - Breeding Goat.csv` | Main partner expense sheet |
| `Data/Notion/*.csv` | Animals, weights, vaccination, deworming, breeding |

### Audit step

`scripts/audit-data.mjs` compares CSV rows against expected totals and writes human-resolved fixes to `data/audit-resolutions.json` (date corrections, row mappings).

`import-all.mjs` **refuses to run** if audit resolutions file is missing.

## Data directories

| Path | Role |
|------|------|
| `data/farm.db.json` | **Runtime DB** in JSON mode; seed source for Supabase |
| `data/audit-report.json` | Audit output (diagnostics) |
| `data/audit-resolutions.json` | Manual fixes applied during import |
| `Data/` | **Read-only** source CSVs (capital D) — not used at runtime |

Note: `data/` (lowercase) is runtime; `Data/` (uppercase) is import source.

## Troubleshooting

### Settlement mismatch after import

1. Check `data/audit-resolutions.json` is current
2. Re-run `npm run audit:data`
3. Compare failing category in `verify-v1.mjs` output
4. Do not patch settlement constants — fix import/source data

### Supabase writes fail locally

- Confirm `SUPABASE_SERVICE_ROLE_KEY` in `.env.local`
- Check RLS policies (service role bypasses RLS)
- Hit `/api/health-check` for loader errors

### Guest can still edit

- Confirm migration 015 applied (`profiles` table exists)
- Check `requirePartner()` is called in the server action
- Verify user role: `select * from profiles where id = '<uuid>'`

### Pages slow in Supabase mode

- Ensure pages use `lib/db/queries.ts` loaders, not full `fetchDb()`
- Check for N+1 patterns in new code

## Git workflow

- `data/farm.db.json` is **committed** — app works out of the box after clone
- Regenerate with `npm run db:reset` when source CSVs change
- Never commit `.env.local`
- Source CSVs in `Data/` are committed as import inputs
